# 论坛系统测试报告

## 一、项目简介

本项目是一款网络在线论坛平台，旨在为用户搭建一个开放的交流与学习社区。平台支持用户完成账号注册、登录等基础操作，同时提供发布原创帖子、回复他人内容、点赞互动、查看收到的互动回复等核心功能，满足用户分享观点、探讨问题、互相学习的需求。此外，系统还配备板块分类、日夜主题切换、站内信、个人资料管理等模块，助力用户打造个性化的论坛社交形象。系统界面美观、使用简便、功能齐全。

本次测试采用**手工测试与 UI 自动化测试相结合**的方式：功能场景以 Selenium 自动化用例（Python 编写）批量执行、断言验证，安全与兼容性以探索性手工测试补充。

### 5. UI 自动化测试实施

本次测试核心产出为一套可重复执行的 Selenium UI 自动化框架，替代人工逐项点击：

```
ForumTest/
├── common/
│   ├── Utils.py        # 浏览器单例 ForumDriver、启动自动打印环境信息、
│   │                   # 截图按 images/日期/第N次测试/ 归档、toast 文案清洗
│   └── DBUtil.py       # 物理删除测试用户及其帖子/回复/站内信，保证用例可重复执行
├── tests/              # 8 个测试类(7 页面对象 + 1 安全测试) + RunTest.py 串行入口（42 条用例）
└── requirements.txt    # 依赖清单
```

框架关键机制（均为实际踩坑后沉淀，详见《测试用例编写指导.md》）：

1. **全程显式等待**（WebDriverWait + expected_conditions），禁止隐式等待与 sleep 混用；toast 用文本条件等待，避免残留提示误判。
2. **CodeMirror 富文本编辑器**通过 JS API（`cm.CodeMirror.setValue()`）操作；编辑页与详情页内容比对统一取 Markdown 渲染区，避免源码与渲染结果不一致。
3. **适配单页应用特性**：不使用浏览器刷新（会重置 SPA 路由），保存/删除后等列表渲染再重新进入详情页验证；计数变化在当前视图轮询 DOM。
4. **数据自恢复**：test01 用户每次运行前重建，admin 昵称/资料/密码用例结束自动还原，测试帖子即建即删、标题带时间戳防同名残留。
5. **日志结构化**：每个模块打印横幅、每条用例打印步骤行，失败时最后一条步骤行即出错用例；toast 统一清洗为单行输出。

**执行结果：42 条用例全部通过（pass 42/42，fail 0/42），可一键重复回归。**

运行方式：

```bash
pip install -r requirements.txt
python d:/test/ForumTest/tests/RunTest.py
```

## 四、测试报告总结

本次针对论坛系统开展了功能测试、安全测试、兼容性测试及 UI 自动化测试，核心覆盖用户注册、登录、板块浏览、帖子发布/编辑/删除、回复与点赞、站内信、个人中心资料与密码管理等业务流程。**42 条自动化用例全部通过，主流程功能正常、数据闭环验证完整，且用例可一键重复回归**；测试中共发现 15 个缺陷（4 严重 / 5 一般 / 6 轻微），系统整体评定为**有条件通过**，建议修复严重缺陷并补充输入校验后回归。

改进建议：

1. 修复搜索功能：排查搜索接口逻辑与前端触发机制，为输入框补 name 属性，确保关键词精准匹配并展示相关帖子；
2. 优化点赞逻辑：增加点赞状态校验（同一用户对同一帖子仅可点赞一次，重复点击取消点赞），杜绝无限刷赞；
3. 完善登录态管理：增加账号登录互斥/会话校验，避免多账号同时登录导致数据覆盖；修复"返回上一级需重新登录"的会话保持问题；
4. 安全加固：对私信、回复等用户输入内容做 XSS 过滤与 HTML 特殊字符转义；注册环节补充用户名格式校验；
5. 补充输入校验：回复/发帖内容增加前后端长度校验（拦截超长内容，禁止数据库原始异常回显）；邮箱、手机号增加格式校验；密码增加强度校验并拒绝与旧密码相同；
6. 完善功能细节：补充评论删除逻辑与权限校验；修正回复时间戳显示；修复头像上传接口；优化删除帖子后资料卡计数的同步刷新；修复密码小眼睛按钮；
7. 持续维护自动化回归集：新增功能同步补充用例并登记 RunTest.py，缺陷修复后将对应"现状记录用例"转为正向断言用例。
